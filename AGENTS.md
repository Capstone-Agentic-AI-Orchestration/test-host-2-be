# AGENTS.md: test-host-2-be

Project memory for agents working in this repository. Read it before changing anything. Keep it short and true; update it in the same pull request when a fact here changes.

## What this is
- The **backend API** of the "Hosting Test Project" project in Alpha. Its frontend is `test-host-2-fe`.
- Node.js + TypeScript + Express 4. `src/app.ts` builds and exports the Express `app` (CORS, JSON body, routes); `src/index.ts` only starts it on `PORT` (default 3000).
- Add routes to `app` (or routers mounted on it), not in `index.ts`, so tests can import `app` without opening a port.

## Run and check
- `npm install`, then `npm run dev` (ts-node). `npm run build` compiles to `dist/` with `tsconfig.build.json`; `npm start` runs `dist/index.js`.
- Before a pull request: `npm run typecheck`, `npm run lint` (`src` and `tests`), `npm test`.

## Contract
- `GET /health` returns `{ "status": "ok" }`. Render polls it and Alpha's post-deploy check uses it: keep it fast, unauthenticated and unchanged.
- Allowed browser origins come from `CORS_ORIGINS` (comma-separated). Locally that includes the Vite frontend on `http://localhost:5173`; add an origin there, never as a literal in code.
- All configuration (ports, URLs, origins, secrets) comes from env; see `.env.example`.

## Tests
- Jest + ts-jest, with supertest for HTTP. Unit tests live in `tests/unit/`, mirror `src/`, and end in `.spec.ts`.
- Test routes through the exported `app` with supertest. End-to-end suites go in `tests/e2e/` as `*.e2e-spec.ts`.

## Branches and CI
- Work lands on `dev`, then is promoted to `uat` and `main`, by pull request only. Never push to those branches directly.
- `.github/workflows/ci.yml` (generated by Alpha from the shared alphaorch-workflow template) runs tests with coverage (threshold 10%), lint and a security scan on pushes and PRs to `dev`, `uat` and `main`. Do not edit it by hand.
- Hosting is Render, set up by Alpha.

## Rules
- This repository is public: never commit secrets, tokens or real customer data. `.env` is git-ignored; copy `.env.example`.
- Commit `package-lock.json` whenever dependencies change.
